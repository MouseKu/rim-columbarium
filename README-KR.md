## 1. 소개

![half.png](C:\Users\Mint\Documents\GitHub\rim-columbarium\.img\half.png)

- 이 모드는 납골당과 유골함을 추가합니다. 유골함에 시신을 화장할 수 있으며, 화장한 시신을 납골당에 보관할 수 있습니다. 

- 납골당은 유골함을 기본 버전 1칸/1개, Compact 버전 1칸/4개를 수용 가능합니다. 좁은 공간에서도 당신의 정착민을 기억할 수 있게 합니다.

- 시신의 생전 스킬 레벨에 따라 다른 꽃이 뜹니다. 예를 들어서 격투 스킬이 높았다면 글라디올러스 꽃으로 치장됩니다.

- 유골함에는 이름과 날짜가 기록되며, 묘비명을 새길 수 있습니다.

## 2. 사용 방법

![step-to-step.jpg](C:\Users\Mint\Documents\GitHub\rim-columbarium\.img\step-to-step.jpg)

1. 예술 작업대에서 유골함을 만듭니다.

2. 화장터에서 화장합니다. 모닥불에서도 할 수 있지만 굉장히 큰 시간과 많은 나무를 요구합니다.

![step-to-step2.jpg](C:\Users\Mint\Documents\GitHub\rim-columbarium\.img\step-to-step2.jpg)

4. 납골당에 유골함을 안치합니다.

![step-to-step3.jpg](C:\Users\Mint\Documents\GitHub\rim-columbarium\.img\step-to-step3.jpg)

5. 묘비명을 새깁니다. 한 번 새긴 묘비명은 바꿀 수 없습니다.

## 3. 아이템 종류

![variation.jpg](C:\Users\Mint\Documents\GitHub\rim-columbarium\.img\variation.jpg)

- 납골당은 8개의 유골함을 저장할 수 있는 버전과 32개의 유골함을 저장할 수 있는 버전이 있습니다.

- 표준 크기의 납골당은 1칸에 1개의 유골함을 보관 가능합니다. Compact 사이즈 유골함은 1칸에 4개의 유골함을 보관 가능합니다. 다만, Compact 크기는 작아서 별도의 Zoom 관련 모드가 없다면 디테일을 보기 어렵습니다.

- 둘 간의 스펙 차이는 거의 없습니다. 표준 크기가 약간의 미관을 줄거에요.

## 4. 기타

- 이 모드는 작업 과정에서 AI를 사용하였습니다.

- 이 모드는 단기 테스트를 통과하였습니다. 현재 장기 세이브 파일 테스트 및 여러 모드와의 호환성을 테스트하고 있습니다. 워낙 단순한 모드고 200개 이상의 모드와 같이 테스트를 수행했어서 버그가 없을 것 같지만 그래도 만약 버그가 발견된다면 제보 주세요.
